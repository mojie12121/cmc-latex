# 全国大学生数学竞赛初赛近十年试题与答案汇编（2016—2025）

本项目收录 **2016—2025 年（第八至十七届）全国大学生数学竞赛初赛**的全部试题及参考答案，使用 XeLaTeX 排版，分别生成试题册与答案册两个 PDF。

全国大学生数学竞赛（Chinese Mathematics Competitions，CMC）由中国数学会主办。初赛由各省（市、区）数学会或军队院校数学教学联席会负责组织，使用全国统一试题，在同一时间内进行考试。竞赛按数学专业类与非数学专业类分别命题；历年类别设置略有调整，本项目按各届实际类别收录。

## 内容

| 年份 | 届次 | 试卷类别 |
| --- | --- | --- |
| 2016 | 第八届 | 数学类、非数学类 |
| 2017 | 第九届 | 数学类、非数学类 |
| 2018 | 第十届 | 数学类、非数学类 |
| 2019 | 第十一届 | 数学 A 类、数学 B 类、非数学类 |
| 2020 | 第十二届 | 数学 A 类、数学 B 类、非数学类 |
| 2021 | 第十三届 | 数学 A 类、数学 B 类、非数学类 |
| 2022 | 第十四届 | 数学 A 类、数学 B 类、非数学类 |
| 2023 | 第十五届 | 数学 A 类、数学 B 类、非数学 A 类、非数学 B 类 |
| 2024 | 第十六届 | 数学 A 类、数学 B 类、非数学 A 类、非数学 B 类 |
| 2025 | 第十七届 | 数学 A 类、数学 B 类、非数学 A 类、非数学 B 类 |

共 30 套试卷，每套满分 100 分、考试时间 150 分钟。试题册只收录题目；答案册收录题目与参考答案、详细解答。排版采用黑白浅色学术风格，每套试卷另起一页，标题按“年份 + 类别”编排。

## 编译

需要 TeX Live 2024（或更新版本），使用 XeLaTeX 编译两次。

试题册：

```bash
xelatex -jobname="全国大学生数学竞赛初赛近十年试题汇编" main.tex
xelatex -jobname="全国大学生数学竞赛初赛近十年试题汇编" main.tex
```

答案册：

```bash
cd answers
xelatex -jobname="全国大学生数学竞赛初赛近十年答案汇编" main.tex
xelatex -jobname="全国大学生数学竞赛初赛近十年答案汇编" main.tex
```

或使用 latexmk：

```bash
latexmk -xelatex -jobname="全国大学生数学竞赛初赛近十年试题汇编" main.tex
cd answers && latexmk -xelatex -jobname="全国大学生数学竞赛初赛近十年答案汇编" main.tex
```
